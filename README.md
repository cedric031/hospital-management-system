# 🏥 Hospital Management System

## Project Overview

The Hospital Management System is a UML-based software design project developed to improve the management of hospital operations. The system provides an organized structure for handling patient records, doctor information, appointments, prescriptions, and billing processes.

This project focuses on system analysis and object-oriented design using UML Class Diagrams.

---

## Objectives

The main objectives of this project are:

- Manage patient information efficiently.
- Store and manage doctor records.
- Schedule and track appointments.
- Generate and maintain prescriptions.
- Handle patient billing information.
- Demonstrate object-oriented analysis and design concepts using UML.

## System Classes

### Patient
Responsible for storing patient information and medical records.

### Doctor
Stores doctor details and specialization information.

### Appointment
Handles appointment scheduling between patients and doctors.

### Prescription
Maintains medication information prescribed during consultations.

### Bill
Stores patient billing and payment details.

---

## UML Relationships

| Relationship | Multiplicity |
|-------------|-------------|
| Patient → Appointment | 1 to Many |
| Doctor → Appointment | 1 to Many |
| Appointment → Prescription | 1 to 0..1 |
| Patient → Bill | 1 to Many |
